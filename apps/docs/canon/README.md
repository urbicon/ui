# Canon

Three pages from the Svelte documentation, vendored here so that anyone (or any agent)
writing docs prose reads them locally instead of fetching them. They calibrate the
register; [docs/EDITORIAL.md](../../../docs/EDITORIAL.md) names the patterns to copy.

Do not edit these files. They are byte-identical to their upstream source and stay that
way. Drift against the live docs is fine: the register is what these files are for, not
the facts.
