# One paragraph, every inline flavor

This sentence mixes **bold text**, *italic emphasis*, ~~a struck-through
aside~~, and an inline `code span` all together, sometimes even **nesting
*italic inside bold*** or `code right next to` **bold** so the boundaries have
to be tracked carefully.

Emphasis also has to survive punctuation: a phrase like **"quoted and bold"**,
an *asterisk\* that is escaped*, and a trailing `snippet.` at the end of a
clause should each resolve cleanly without swallowing the following text.
